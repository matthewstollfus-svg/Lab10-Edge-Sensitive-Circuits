## Lab Questions

### What is difference between edge and level sensitive circuits?
    level sensitive changes when the enable input is on or through the entirety of 1, while edge is only on the transition.
### Why is it important to declare initial state?
    Makes the circuit predictible when it first starts.
### What do edge sensitive circuits let us build?
    counters and memory.
